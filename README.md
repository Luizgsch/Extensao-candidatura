# Assistente de Candidaturas

Parte 2: infraestrutura e contratos. Sem popup ou preenchimento nesta versão.

## Ambiente

Node.js 24 e npm. Instale com npm ci. Valide com npm run check. Compile com npm run build.

## Instalação local

Na página de extensões do Chrome ou Brave, ative modo de desenvolvedor e carregue dist como extensão sem compactação. O ícone ainda não abre interface.

## Privacidade

Sem backend, telemetria ou chamadas externas. Dados pessoais não estão incluídos. Armazenamento restrito aos contextos confiáveis. Não é cofre criptografado. Nunca envia candidaturas.

## Publicação futura

Build separado em dist. Publicação exigirá ícones, política de privacidade, telas, revisão de permissões e validação nas lojas.

Veja docs/architecture.md.
